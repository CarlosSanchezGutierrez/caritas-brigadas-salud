## Rejection criteria

Reject production readiness review entry when evidence is missing, stale, synthetic, unsanitized, untraceable, inconsistent with API contract version, missing pilot evidence review reference, missing release candidate reference, missing operational owner assignment, missing security review evidence, missing privacy review evidence, missing backup and recovery evidence, unresolved critical defects, unowned risks, or claiming production approval without real evidence.

## P3.27 conclusion

Production readiness review entry must remain evidence-driven across Web iOS Android.
