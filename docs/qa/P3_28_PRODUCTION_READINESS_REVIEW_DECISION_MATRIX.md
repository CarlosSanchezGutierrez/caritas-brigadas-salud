## Rejection criteria

Reject production readiness review execution when evidence is missing, stale, synthetic, unsanitized, untraceable, inconsistent with API contract version, missing review entry reference, missing security review evidence, missing privacy review evidence, missing data governance review evidence, missing backup and recovery review evidence, missing rollback rehearsal evidence, missing incident response rehearsal evidence, unresolved critical defects, unowned risks, or claiming production approval without real evidence.

## P3.28 conclusion

Production readiness review execution must remain evidence-driven across Web iOS Android.
