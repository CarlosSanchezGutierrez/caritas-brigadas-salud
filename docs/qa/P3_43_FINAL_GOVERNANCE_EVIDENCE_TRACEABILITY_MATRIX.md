## Rejection criteria

Reject final production governance evidence index when evidence is missing, stale, synthetic, unsanitized, untraceable, inconsistent with API contract version, missing post transition monitoring review reference, missing final production governance evidence index package evidence, missing phase index entry, missing evidence owner evidence, missing evidence location evidence, missing evidence version evidence, missing evidence freshness evidence, missing evidence approval evidence, missing evidence completeness evidence, missing evidence traceability evidence, missing evidence sanitization evidence, missing evidence gap register, missing blocker register, missing exception register, missing residual risk register, missing P4 implementation readiness handoff evidence, missing P4 real evidence backlog evidence, unresolved critical blockers, unowned exceptions, or claiming backend production readiness approval without real institutional evidence.

Final governance evidence traceability matrix must remain evidence-driven across Web iOS Android.
