# caritas-brigadas-salud
Repositorio para plataforma móvil, web y analítica para las brigadas de salud de Cáritas de Monterrey, permitiendo que estudiantes del Tec de Monterrey contribuyan en áreas de desarrollo móvil, web, backend, bases de datos, ciberseguridad, redes, analítica, ingeniería de datos, ciencia de datos, IA, criptografía y documentación técnica.
